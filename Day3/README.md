# Networking Basics – Observations

## 1. What did you observe when running networking commands?

When I ran networking commands, I observed that the system sends packets to the destination and receives packets in response.

## 2. What did ping show you?

The ping command showed whether the destination machine is alive or not.

## 3. What does DNS do in simple words?

DNS assigns IP addresses to domain names. It converts human-readable names into IP addresses so that computers can communicate with each other.
