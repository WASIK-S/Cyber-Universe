## 2️⃣ One Error I Faced and What Happened

When I used the copy command (`cp`), I faced an issue. I tried to copy the file to the destination, but it did not copy.

### Error I Made

```bash
cp file1.txt /Downloads
````

### Explanation

* `/` = Root directory
* `/Downloads` = Downloads folder inside root
* `~/Downloads` = Downloads folder inside your home directory

### How I Fixed It

```bash
cp file1.txt /home/abbu/Downloads
```

After that, I learned that I forgot to mention the home directory symbol `~`.
